# Regla de Repositorios GitHub Selectra-Dev y Prohibición de ZIPs

1. **Alojamiento Exclusivo en la Organización**:
   - Todo proyecto, herramienta o script creado por Power Users DEBE residir exclusivamente en la organización oficial de GitHub:
     `https://github.com/Selectra-Dev/<nombre-repositorio>`
   - Está TERMINANTEMENTE PROHIBIDO crear proyectos en cuentas personales de GitHub o descargarlos como archivos ZIP.
2. **Onboarding de Power Users sin cuenta**:
   - Si no tienes cuenta en GitHub o no estás añadido a `Selectra-Dev`, la IA te ayudará a:
     a) Registrar tu cuenta en https://github.com/signup con tu correo corporativo (@selectra.com o @selectra.info).
     b) Habilitar la Autenticación de Dos Factores (2FA).
     c) Generar la solicitud formal en el canal de Google Chat `Safari Zone` para que DevOps te invite a `Selectra-Dev`.
3. **No ZIP Files**:
   - Ningún asistente de IA (Claude, Cursor, Antigravity) debe entregar código en archivos comprimidos ZIP. La entrega canónica se realiza mediante `git push origin main` hacia `Selectra-Dev`.
