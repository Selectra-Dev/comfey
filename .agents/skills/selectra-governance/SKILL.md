# Selectra Safari Zone Governance Skill

Esta habilidad proporciona soporte continuo para:
- Scaffold de nuevas funcionalidades y módulos.
- Conexión con GitHub Selectra-Dev.
- Persistencia stateless en Google Cloud Firestore y Google Cloud Storage.
- Consulta al Catálogo de APIs y microservicios internos.
- Auditorías previas al despliegue.
- Generación de solicitud de despliegue ("Boleto Dorado").
